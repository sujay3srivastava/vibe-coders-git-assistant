# Vibe Coder's Git Assistant

A Claude Desktop plugin that seamlessly integrates version control into the coding experience for non-technical users. The tool automatically commits code changes made by Claude to a Git repository, creating a safety net that allows users to easily revert to previous versions of their code when needed.

## Core Objective

To make version control accessible and intuitive for beginners who are using Claude to help them code, by automating Git operations and providing natural language navigation through code history.

## Target Audience

- Beginner coders and "vibe coders" who use Claude to help them write code
- Users with limited or no experience with Git and version control systems
- Non-technical individuals exploring coding through AI assistance
- People learning to code who want protection against destructive changes

## Core Features

1. **Automatic Git Integration**
   - Automatic GitHub repository creation if one doesn't exist
   - Seamless connection to existing repositories
   - Automatic detection of code changes made by Claude

2. **Automatic Commit Functionality**
   - Commits after each Claude prompt/response cycle
   - Includes prompt text in commit messages for context
   - Categorizes changes (e.g., "New Feature", "Bug Fix")

3. **Natural Language Version Navigation**
   - Revert to previous versions using natural language
   - Simple terminology that doesn't require Git knowledge

4. **Simplified History Visualization**
   - High-level summaries of changes
   - Chronological timeline with descriptive labels

5. **Claude MCP Integration**
   - Deep integration with Claude Desktop via Model Context Protocol
   - Authentication and permission handling for GitHub
